# Code of Conduct

## Our commitment

The Motech Audit Solidity Security Lab is a learning and collaboration space for people working with Solidity, Foundry, and smart-contract security. We want participation to be respectful, constructive, and welcoming to people with different backgrounds and experience levels.

## Expected behavior

- Be respectful and assume good intent where reasonable.
- Give constructive, specific technical feedback; critique code and ideas, not people.
- Welcome beginner questions and explain security concepts without belittling others.
- Keep discussions focused on the project and its educational purpose.
- Respect privacy and confidentiality. Do not post client code, private audit reports, credentials, or non-public vulnerability details.
- Follow the repository's [Security Policy](SECURITY.md) when reporting sensitive security concerns.

## Unacceptable behavior

- Harassment, personal attacks, threats, discrimination, or intimidation.
- Insults or humiliating language aimed at a contributor's experience or identity.
- Publishing another person's private information without permission.
- Posting confidential client materials, secrets, or sensitive vulnerability details in public.
- Spam, repeated off-topic promotion, or deliberately disruptive behavior.

## Scope

This Code of Conduct applies to repository Issues, Pull Requests, code reviews, Discussions, and project-related spaces where someone is representing the project.

## Reporting concerns

Please contact the repository maintainers privately through GitHub where a private contact route is available. If you cannot find one, open an Issue titled **“Request for private conduct contact”** without including private, identifying, or sensitive details in the public issue. The maintainers can then provide a suitable route for the report.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead. Do not disclose exploit details or confidential information in a public report.

## Enforcement

Maintainers may edit or remove inappropriate content, close discussions, or restrict participation for behavior that violates this Code of Conduct. Responses should be proportionate to the behavior and intended to protect a respectful, constructive project environment.
